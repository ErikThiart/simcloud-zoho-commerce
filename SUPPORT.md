# Support

For installation or code defects, open a [GitHub issue](https://github.com/ErikThiart/simcloud-zoho-commerce/issues) with the extension version, PHP version, Zoho region/plan, expected behaviour and a redacted failure description. Include controlled event labels and HTTP status if useful. Do not include raw provider responses or private credentials.

For a paid purchase whose outcome is uncertain, preserve the saved reference/provider ID and reconcile privately with SIMcloud. Do not reset the claim, repeat the checkout or run another purchase to test the account.

Start with the [installation guide](docs/installation.md) and [verification checklist](docs/verification.md). A reviewed marketplace release is not yet available. This repository documents a standalone developer installation.
