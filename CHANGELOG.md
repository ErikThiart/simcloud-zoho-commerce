# Changelog

## 0.2.0-alpha.2

- Public standalone developer source for the Zoho Commerce sidebar/settings widgets and procedural PHP merchant connector.
- Data and VAS catalogue imports, fixed-value airtime/electricity products and 23 bundled brand images.
- Merchant-edit preservation, encrypted delivery data, payment gates, durable submission claims and bounded reconciliation.
- Unbound default packages; account-specific API/connection metadata is supplied only through explicit local build options.
- Explicit runtime file lists and public-source/package checks in local tooling and CI.
- Generic installation, architecture, API mapping, security, testing and Marketplace preparation guides with synthetic demonstration screenshots.

This alpha still requires connected-store, checkout, gateway, delivery and Marketplace acceptance. It does not include a hosted account signup service or a production website backend.
