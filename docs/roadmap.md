# Roadmap

1. Complete native widget/API Configuration acceptance in supported development stores.
2. Verify service-specific inputs, checkout, gateway response fields and funded delivery with owner approval.
3. Reduce manual setup by packaging supported layouts and order-workflow components.
4. Complete merchant deployment, revocation, backups, mail and data-retention acceptance.
5. Submit a tested, documented extension for Zoho Marketplace review.

A one-click merchant experience is the goal. Account consent, payment-provider setup and explicit live-spend settings remain necessary. Keep account-specific implementation and operational evidence outside this public repository.
