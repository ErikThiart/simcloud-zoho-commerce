API Configurations require SDK 2.0 or later. The widget includes the vendor's v2.0 script; some documentation examples may link an older script. Verify the actual installed runtime and account entitlements.

Only public SIMcloud API paths and public image-source URLs are documented here. Product-logo origins and hashes are in [the source manifest](../app/images/sources.json). This reference list does not establish account authorization, connected checkout or paid delivery.
